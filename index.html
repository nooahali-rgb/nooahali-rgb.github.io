Multipost Video Uploader

A dedicated personal automation tool built exclusively to upload the owner's own videos directly to the owner's verified YouTube channel.

Read Privacy Policy Contact Owner

100% Personal Use

Multipost is operated solely by its owner for their own content publishing. It is not offered as a multi-user SaaS or commercial service.

Direct YouTube API

Uses official Google YouTube Data API v3 endpoints strictly to upload creator videos, set thumbnails, and manage publishing metadata.

Zero Data Sharing

No user data is ever collected, sold, or shared with third parties. State and queue logs are preserved only in the owner's private repository.

How Multipost Operates

Multipost runs automated tasks configured by the owner:

  • Reads video files authored by the channel owner from a designated inbox queue.
  • Connects securely to the owner's YouTube channel using OAuth 2.0 credentials.
  • Uploads the video with owner-provided metadata (title, description, tags, category).
  • Records completion status into a private repository database to prevent duplicate uploads.

For detailed disclosures regarding Google API scopes, data handling, and compliance with the Google API Services User Data Policy, please review our Privacy Policy.
